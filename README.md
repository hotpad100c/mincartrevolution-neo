# MinecartRevolution Neo

一个Minecraft NeoForge模组，为游戏添加更多有趣的矿车功能！

## 功能特性

- 更多种类的矿车实体

## 安装说明

### 前置要求

- Minecraft 26.1.2
- NeoForge 26.1.2.36-beta

### 安装步骤

1. 从[GitHub Releases](https://github.com/hotpad100c/minecartrevolution-neo/releases)下载最新的模组JAR文件。
2. 将JAR文件放入Minecraft的`mods`文件夹中。
3. 启动游戏，确保NeoForge已安装。

### 开发环境设置

1. 克隆此仓库：
   ```bash
   git clone https://github.com/hotpad100c/minecartrevolution-neo.git
   ```

2. 打开项目在IntelliJ IDEA或Eclipse中。
